# 0113 冻结连续行动组的单变量变体与预测

- 状态：已接受
- 日期：2026-07-27
- 来源决定：CA-05

## 决策

三个核心角色分别采用：

- `CA-R1`：*FOOTSIES* 的“允许空振取消”由否改为是，预测相同缓存请求只在变体中进入新动作；
- `CA-R2`：id 移动夹具由每个空中子步读取当前方向改为片段入口锁存，预测变体的水平第二轴速度与位移始终为零；
- `CA-R3`：osu!lazer 的同一候选由立即裁定改为延迟 `75 ms` 裁定，预测正式结果由 `Great` 变为 `Ok`；
- 负对照：osu!lazer 命中动画开关改变绘制路径，但不得改变任何正式结果或计分状态。

每项变体在结果产生前冻结初态、输入、时间基准、唯一逻辑变量、不变量、预测、结果读取方法、反驳条件与无效条件。

## 为什么采用这些变体

改变 *FOOTSIES* 的命中位置或取消窗会混入碰撞或输入时序；“允许空振取消”直接隔离缓存后的许可门。改变 Quake III 的加速度只证明参数影响轨迹，不能检验运行中的输入采样。改变 osu!lazer 的判定窗只证明阈值影响分类；延迟同一裁定路径更直接地区分候选时刻和正式结果时刻。
