# 0109 冻结连续行动组的核心失真与检验命题

- 状态：已接受
- 日期：2026-07-27
- 来源决定：CA-01

## 决策

连续行动组采用[核心失真与可反驳命题](../../research/continuous-action-pilot-ca-01.md)：以工作标签“原子动作别名化”指称被测失真，检验把**输入**识别到**效果**提交之间具有规则意义的边界压成单一动作或无类型状态转换时，是否会使结构不同的设计无法被独立重构和事前区分。

只有同时满足规则可查询、可独立改变和具有反事实后果的中间边界才进入检验。正式结果至少区分：压缩表示被证实不足、核心命题被反驳、区别成立但当前表示存在缺口，以及证据不足导致结论不定。

## 为什么采用这一方向

“输入不是动作”过窄；“动作、过程、事件不可互换”若没有变体预测容易成为术语宣言；“多时钟”或**调度语义**容易滑向实现审计；**行动实现载体**又容易混入玩家能力和硬件噪声。当前方向用同一个反事实判据约束这些接口，不因字段更多就宣布模型更好。

## 影响

- CA-02 按被隔离的因果接口设置案例职责，不按平台、格斗、节奏等类型平均分席位。
- 本决定不新增“连续动作原语”，也不把“原子动作别名化”录入**共享术语**。
- CA-03–CA-07 仍须冻结作品、版本、表示、单变量变体、执行角色、污染规则与正式放行条件。
- CA-01 可以在后续证据下被反驳或修订；“已冻结”只表示后续测试不能在看到结果后回写命题。
