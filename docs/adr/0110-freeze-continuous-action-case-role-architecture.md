# 0110 冻结连续行动组的案例职责架构

- 状态：已接受
- 日期：2026-07-27
- 来源决定：CA-02

## 决策

连续行动组采用[三个核心案例角色和一个条件角色](../../research/continuous-action-pilot-ca-02-case-roles.md)：识别—锁定入口、调制—轨迹运行、候选—裁定出口，以及只在前三者不能隔离反馈时启用的反馈—再进入闭环。每个核心角色须独立满足 `CA-H01`–`CA-H04`，不能由其他角色补足。

案例角色按输入识别到效果提交之间的因果接口定义，不按游戏类型分配席位；角色数也不等于作品数。整组另设反馈闭环义务与实现噪声负对照。

## 为什么采用这一架构

按平台、格斗、节奏或竞速配额选案会把类型覆盖误当作变量隔离；固定四个并列角色又会预设反馈与前三个接口具有相同证据地位。三个核心角色正好覆盖 CA-01 的声明区间，条件角色则保留“效果不等于参与者已经获知”的独立压力。

原提议中的“承诺—展开锚点”改为识别—锁定入口，因为 [ADR 0091](0091-model-decision-locking-without-a-commitment-primitive.md) 已决定用**锁定点**描述权限变化，不设“承诺原语”。

## 影响

- CA-03 先按来源确定性、单变量可隔离性和轨迹可复算性选案，再考虑知名度与类型代表性。
- 角色名称是测试工作标签，不进入**共享术语**或公开理论层级。
- 若中途输入形成新动作，归入入口角色；若只调节同一过程，归入运行角色。
- 若后续主张玩家行为或体验，仍须另行取证。
