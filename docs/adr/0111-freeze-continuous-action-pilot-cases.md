# 0111 冻结连续行动组的案例与版本

- 状态：已接受
- 日期：2026-07-27
- 来源决定：CA-03

## 决策

连续行动组采用三个正式来源锚点：

- `CA-R1`：*FOOTSIES* 标签 `1.5.0`、提交 `7eaaad799bb7912625c15af9407c2c67e6305d75`；
- `CA-R2`：id Software *Quake III Arena* GPL 源码提交 `dbe4ddb10315479fc00086f08e25d968b4b43c49` 的移动模块；
- `CA-R3`：osu!lazer 标签 `2026.726.0-lazer`、提交 `5da71008b082d1a77e4bb301dc98886f1f24b895`。

三者分别隔离已识别请求越过许可门、运行过程继续读取输入，以及候选发生进入正式裁定。条件角色 `CA-R4` 暂不启用；osu!lazer 另承担装饰反馈负对照。

## 为什么采用这些案例

这三个制品都能由权利人或开发者官方源码定位待测关系，并允许项目在相同基础上构造可复算的单变量反事实。跨格斗、第一人称动作和节奏游戏有助于避免把单一引擎惯例当作普遍结构，但类型覆盖不是席位依据。

*FOOTSIES* 正式身份采用 `1.5.0`，因为它与官方项目页、发布页和源码提交能直接对应；同提交上的其他标签与发布附件命名不用于声称二进制对应。id 案例明确称为 GPL 源码移动模块，不冒充零售可执行文件。

## 停止与替补

若声明工具链无法恢复，或必须修改多项玩法语义才能运行，失败制品保留并切换预定备选：`CA-R1` 使用 *Celeste 64*，`CA-R2` 使用 SuperTuxKart，`CA-R3` 重选同一官方仓库明确标签。任何切换都要发布 CA-03 小版本并重新冻结预测。
