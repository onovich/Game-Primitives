# 0115 冻结连续行动组的制品、彩排与放行

- 状态：已接受
- 日期：2026-07-27
- 来源决定：CA-07

## 决策

连续行动组使用 `research/calibration-tests/continuous-action-pilot/` 保存七个 Schema 家族、增量彩排和不可回写的正式轮次 `continuous-001`。

正式证据链为“来源编码 → 来源审核 → 两条件独立重构 → 同一执行者继续预测 → 确定性执行 → 真值揭示 → 分轴报告”。第一阶段提交引用到第二阶段预测，预测集合引用到执行结果，执行结果再引用到揭示和报告。

## 增量彩排

正式材料使用前，只用虚构确定性系统彩排本轮新增的两阶段派发和预测后执行顺序。失败彩排永久保留，修复使用新编号；不重复把逻辑组已验证的全部基础步骤包装成新成果。

## 正式放行

CA-07 只授权准备 Schema、来源编码、审核、夹具、比较器和增量彩排，不授权正式盲测、冻结正式输入的精确运行或揭示。正式包冻结并推送后，向作者展示制品、哈希、真值承诺、彩排和执行边界，取得一次“放行正式连续行动试验”的明确指令。

放行后按协议连续执行，不逐阶段请求批准；失效、来源切换或权限扩张时才停止。

## 影响

详细目录、散列算法、阶段顺序和失效纪律见 [CA-07](../../research/continuous-action-pilot-ca-07-artifacts-and-release.md)。本决定不增加**共享术语**或公开理论层。
