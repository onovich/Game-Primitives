# 0114 冻结连续行动组的执行与结论规则

- 状态：已接受
- 日期：2026-07-27
- 来源决定：CA-06

## 决策

连续行动正式轮次使用 `1＋1＋2＋2`：一名**来源编码者**、一名来源忠实度审核者、两名丰富视图重构／预测者和两名压缩视图重构／预测者。主编线程担任测试保管者，确定性程序承担运行和比较。

盲测分两阶段：先冻结独立重构首次提交，再向同一会话派发中性变体信封并冻结预测。丰富与压缩条件使用不同空白会话、相同模型参数和逐字节相同的任务、顺序、信封与输出格式。

## 污染与范围

作品或规则熟悉度只限制材料自足性证据，不自动使提交失效；另一视图、答案、结果、他人提交、包外文件或外部检索属于逐阶段完整性污染。结果全局泄漏、冻结字节被覆盖或承诺无法复算使轮次无效。

本轮 `behavior_scope` 为 `structural_only`。不增加独立标注者或行为参与者，也不主张技能、难度、策略、平衡、手感或体验。

## 结论

每个核心角色分别报告压缩命题与当前表示两条轴；组级保留三角色向量，不使用综合分数。三个角色全部通过、负对照通过且载体与反馈义务闭合，才可判为**范围内通过**。任一有效紧凑表示反例会反驳冻结的组级核心命题；来源或变量不足返回**结论不定**；边界成立但 CA-SR 无法表达或稳定传递，返回**模型失败**。
