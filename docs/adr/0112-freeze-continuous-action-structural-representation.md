# 0112 冻结连续行动组的测试伴随表示

- 状态：已接受
- 日期：2026-07-27
- 来源决定：CA-04

## 决策

连续行动组使用 [CA-SR 0.1](../../theory/CONTINUOUS-ACTION-REPRESENTATION-0.1.md) 保存多时间基准、输入识别路径、动作生命周期、过程更新、候选裁定、反馈可得性和可复算轨迹。

CA-SR 0.1 继承 GP-SR 0.1 的基础类型、十一项**规则槽位**、八种组合关系与四种来源编码状态，并增加测试局部记录、显式运行关系和机械生成的压缩负对照。

## 为什么采用伴随表示

直接修改 GP-SR 0.1 会改变已经用于 `logic-001` 的冻结受测对象；只用自然语言补充连续事实又会让重构依赖说明区。独立伴随表示既保留逻辑组的版本历史，又让连续组明确接受“当前字段仍可能失败”的检验。

## 边界

- CA-SR 0.1 不是 GP-SR 0.2、完整 DSL 或公开理论新层级；
- 记录类型与关系不因进入 Schema 自动成为**原语**；
- 来源事实无法承载时记录 `representation_gap`，不得运行中增加字段；
- 角色视图和压缩视图必须从单一事实源机械生成；
- 压缩视图若仍能完成重构和预测，CA-01 必须接受反驳。

## 影响

本决定不修改项目词表、CONTEXT 或公开“原语 → 机制 → 玩法模板 → 游戏”主线。
