# rehearsal-001

本轮是连续行动试验的增量排演，不是理论证据。

它使用一个无游戏身份的虚构两步系统，验证以下程序：

1. 冻结两种条件视图和一个字节相同的变体信封；
2. 在互相隔离的空白会话中先取得重构首次提交；
3. 冻结重构提交后，才向原会话派发变体预测任务；
4. 冻结预测后，执行确定性夹具；
5. 最后揭示条件映射、真值和承诺随机数；
6. 复算承诺、核对提交链并形成排演报告。

排演只判断工件、顺序、散列与隔离流程能否工作。任何重构或预测结果都不得用于支持或反驳连续行动理论。
