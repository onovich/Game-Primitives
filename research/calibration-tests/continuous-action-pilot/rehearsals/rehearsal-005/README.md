# rehearsal-005

本轮是盲测回答接口的聚焦彩排，不重跑虚构夹具，不揭示真值，也不产生理论证据。

它使用两个全新空白会话，分别覆盖：

- `condition-v01`：结构可唯一恢复，预测应可确定；
- `condition-v02`：结构不可唯一恢复，预测应保持不确定并列出相容替代。

每个会话都从重构继续到预测。只接受两阶段原始首答；格式或跨文件约束失败时不得让同一执行者修改。报告只检查原始回答可操作性、同会话连续性、原始证据绑定与确定性装配。

输入、结构模板与任务在派发前冻结。结果保存在 `raw/`、`envelopes/`、`submissions/` 与 `reports/`。
